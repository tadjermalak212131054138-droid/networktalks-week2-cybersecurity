# NetworkTalks — Week 2 Cybersecurity Internship

Week 2 cybersecurity internship practicals: Footprinting with Kali Linux and network discovery using Zenmap.

## Overview

This repository documents my Week 2 practical activities as part of the Cybersecurity Internship at NetworkTalks.

The work covers two practical modules:

- **W2-PM1:** Footprinting and reconnaissance using multiple Kali Linux tools.
- **W2-PM5:** Local network discovery and topology mapping using Zenmap.

## Modules Completed

### W2-PM1 — Footprinting with Kali Linux

The following tools were used within the authorized scope:

1. WHOIS — domain registration information.
2. WhatWeb — website technology identification.
3. Nslookup — DNS resolution.
4. Curl — HTTP response-header inspection.
5. WAFW00F — Web Application Firewall identification.
6. DNSRecon — DNS record enumeration.

### W2-PM5 — Network Scanning with Zenmap

The practical involved:

- Identifying the local IP address and subnet.
- Discovering live hosts on my own local network.
- Recording IP and MAC address information where available.
- Viewing the network topology.
- Exporting the topology as a PDF.

## Repository Structure

- `PM1-Footprinting/` — command outputs and screenshots from the six reconnaissance tasks.
- `PM5-Zenmap/` — network scan evidence and exported topology.
- `Report/` — final Week 2 penetration-testing report.

## Scope and Authorization

The practical activities were conducted for educational purposes and within the authorized scope. The local network discovery activity was limited to my own network or networks for which permission was obtained.

The results are observations from the exercises and do not represent confirmed vulnerabilities.

## Learning Outcomes

This practical work helped me understand domain footprinting, website technology identification, DNS enumeration, HTTP headers, WAF detection, local network discovery and network topology documentation.
